# Repository Context

This project uses two repositories:

* Main repository: `nu-shinkan`
* Wiki repository: `docs`

The wiki repository must be available at:

`[nu-shinkan repository root]/docs/`

If `docs/` is missing or unavailable at that location, stop the task and report the problem. Do not proceed by assuming or reconstructing its contents.

Before performing substantial repository work, follow:

`docs/instructions/context-discovery.md`
